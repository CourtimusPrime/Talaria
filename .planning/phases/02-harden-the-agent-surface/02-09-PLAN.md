<objective>
Close SEC-02 and give CRED-03 its storage half: the vault gains a write path, and importing a
plaintext credential file stops leaving that file on disk.

Purpose: `Vault` exposes only load, save and domain matching. Nothing in the shell ever pushes a
credential entry, so save only ever rewrites what was loaded and the only way to populate the vault is
to hand-write a plaintext file — which the import path then reads, encrypts, and leaves sitting there
indefinitely with default permissions. The user believes the import migrated them. Separately, the
key-file fallback discards the result of its permission change, so a failed attempt to make the key
owner-only is invisible, and the keychain-unavailable downgrade reaches the user only through a
warning the shell has no surface to display.

Output: An upsert and delete API on the vault, a verified-then-remove import, a checked permission
change, one-shot notices the chrome can render, and an e2e suite that proves the import and its
cleanup survive a restart.
</objective>

```rust
    pub fn save(&mut self) {
        let Some(cipher) = &self.cipher else { return };
        let Ok(plain) = serde_json::to_vec(&self.entries) else { return };
        let nonce = ChaCha20Poly1305::generate_nonce(&mut OsRng);
        let Ok(ciphertext) = cipher.encrypt(&nonce, plain.as_slice()) else { return };
        /* MAGIC + nonce + ciphertext */
        if let Err(error) = fs::write(&self.path, data) {
            log::warn!("could not write vault: {error}");
        }
    }

    /// Entries whose URL host matches `domain` (exact or subdomain).
    pub fn matching(&self, domain: &str) -> Vec<CredentialEntry> {
        let domain = domain.trim().trim_start_matches('.').to_ascii_lowercase();
        self.entries.iter().filter(|entry| {
            url::Url::parse(&entry.url).ok()
                .and_then(|u| u.host_str().map(str::to_ascii_lowercase))
                .is_some_and(|host| host == domain
                    || host.ends_with(&format!(".{domain}"))
                    || domain.ends_with(&format!(".{host}")))
        }).cloned().collect()
    }
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plaintext credential file -> vault import | An attacker-readable file holding the user's passwords in cleartext, which today survives the import |
| vault key file -> filesystem | On keychain-less systems the key sits beside the ciphertext, so its permissions are the only protection |
| agent credentials-read -> vault entries | An agent reads matching entries by domain; a partially written entry list must never be visible |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09-01 | Information Disclosure | plaintext credential file surviving the import with default permissions | high | mitigate | The source is removed after the encrypted write is verified by re-reading and decrypting it; a failed verification chmods the source owner-only and logs at error level naming the path |
| T-02-09-02 | Information Disclosure | key file left group- or world-readable because the permission result was discarded | high | mitigate | The permission call's result is checked; failure logs at error level and sets the downgrade notice |
| T-02-09-03 | Repudiation | user believing credentials were migrated when they were not | high | mitigate | Both outcomes set a one-shot notice with different text, giving the chrome something to show; the log alone is explicitly treated as insufficient |
| T-02-09-04 | Tampering | encryption failing silently and the plaintext being deleted anyway | high | mitigate | Removal is gated on a successful re-read, decrypt and entry-count match, so a save that silently returned early cannot cause data loss |
| T-02-09-05 | Tampering | an agent reading a half-written entry list | medium | mitigate | Vault access happens only on the winit main thread, with no borrow held across a call into Servo; a write completes within one borrow scope |
| T-02-09-06 | Denial of Service | a malformed plaintext file aborting startup | low | mitigate | The existing degrade-never-abort rule is preserved: a malformed file yields an empty entry list and a warning, never a panic |
| T-02-09-07 | Information Disclosure | keychain downgrade reaching only a log the user never reads | medium | mitigate | Every one of the four keychain fallback branches sets the downgrade notice, not just the branch that happens to fire most often |
| T-02-09-08 | Tampering | package installs | n/a | accept | No npm/pip/cargo package is installed and no dependency is added; the encryption and keyring crates are already workspace dependencies. No legitimacy gate applies |
