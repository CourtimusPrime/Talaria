<objective>
Build the shell half of AGENT-04: tab lifecycle events become owner-addressed and stop being
silently discarded under reentrancy.

Purpose: `broadcast_event` sends every crash and close to every connected session, so agent A is told
about agent B's tab ids. Worse, it is guarded by a `try_borrow` that silently drops the event
entirely when the session table is momentarily borrowed — and six sibling delegate callbacks have the
same shape, dropping a popup adoption, a crash mark, a close, and a URL update on contention. A
notification path that silently drops under reentrancy is not a notification path, so this has to be
fixed before plan 02-08 surfaces anything to MCP clients.

Owner filtering is correct addressing, not the per-agent policy layer PROJECT.md rules out of scope.

Output: An owner-addressed event queue and a deferred tab-table work queue, both drained from the
event loop with the house split-scope idiom, every silent-drop path removed or made loud, and an e2e
proof that an event reaches its owner and nobody else.
</objective>

    pub fn process_pending_captures(&self) {
        let mut due = Vec::new();
        {
            let mut pending = self.pending_captures.borrow_mut();
            /* ... move due entries into `due` ... */
        }
        for capture in due {
            let outcome = self.capture_now(&capture.webview, &capture.context, true);
            let _ = capture.reply.send(outcome);
        }
        self.process_pending_loads();
    }

The broadcast to replace (`crates/talaria-shell/src/app.rs:365-376`):

```rust
    /// Push an unsolicited event to every connected control client.
    /// Non-blocking (unbounded channel), so this is safe to call from servo
    /// delegate callbacks.
    pub fn broadcast_event(&self, event: talaria_protocol::Event) {
        if let Ok(sessions) = self.sessions.try_borrow() {
            for session in sessions.values() {
                let _ = session
                    .events
                    .send(talaria_protocol::ServerMessage::Event { event: event.clone() });
            }
        }
    }
```

    get that far before deciding to defer.

    vector under a scoped borrow, drop the borrow, then act. Nothing inside the scoped borrow may call
    into Servo. Say that in a comment on each drain, because it is what makes the producer side's
    borrow attempt unable to contend in the first place.

    The event drain, for each entry, looks the addressee up in the session map and sends on that one
    session's channel. A session that has since disconnected is simply absent from the map and its
    entry is discarded — that is correct, not a drop, and deserves a one-line comment saying so. The
    send result stays explicitly ignored, matching the existing fire-and-forget convention.

    The tab-work drain applies each variant against the tab table: adoption resolves the parent's owner
    and whether the parent was active, then registers the webview the same way the inline path does;
    the crash variant finds the tab by webview and marks it; the close variant reads the owner, closes,
    and queues the corresponding event; the URL variant applies the location update and clears the
    blank-grace window under the same condition the inline path uses.

    already calls the pending-loads drain, so all three winit handlers reach them without touching
    each handler. Add nothing to `next_capture_deadline` for these queues — they are ready the moment
    they are enqueued rather than deadline-driven — but make every producer request a redraw, which is
    the existing mechanism for waking the loop and is already present at each site.

    Replace `broadcast_event` with a method that takes an owner reference and an event: it returns
    without doing anything for a human-owned tab, and otherwise pushes an entry onto the event queue.
    Give it a doc comment stating that a session sees events only for its own tabs, and that this is
    addressing rather than policy. Delete the old broadcast so no caller can bypass the filter.

    request unconditional.

    In the crash test hook inside the evaluate arm, read the owner from the tab it marks and queue
    against it, so the hook exercises the same addressed path the real callback does — the e2e suite
