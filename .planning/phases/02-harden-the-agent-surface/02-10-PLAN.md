<objective>
Close CRED-03's capture half and CRED-02: a user can save a credential from inside Talaria, and a
stored credential is suggested back by domain match in the chrome.

Purpose: the vault is populatable as of plan 02-09 but nothing in the browser calls that API, and
there is no autofill surface at all — the credentials-read command returns an empty list on a fresh
install, so one of the product's headline features is inert. This plan is the phase's capture path.

Two deliberate boundaries, both from the phase decisions. Per D-22, a browser-style save-password
prompt on form submit is deferred: it needs form-submission interception through a Servo delegate, a
materially bigger surface than the rest of this phase, so the manual panel below is this phase's
capture path and no form-submit hook is added. And per D-23, autofill surfaces as a toolbar suggestion
rather than inline page-DOM injection, because injection would collide with the agent's own scripting
and needs form-field detection neither side has.

Output: A credentials panel, a domain-matched toolbar suggestion, a one-shot notice surface, and an
input-driven e2e proof that a credential typed in the chrome is readable through the same command an
agent uses.
</objective>

```rust
fn apply_ui_actions(state: &Rc<Shared>, actions: Vec<UiAction>) {
    for action in actions {
        match action {
            UiAction::SwitchMode(mode) => {
                let mut tabs = state.tabs.borrow_mut();
                tabs.mode = mode;
                tabs.sync_visibility();
                drop(tabs);
                state.window.request_redraw();
            },
            /* ... */
```

The collect-intent pattern (`crates/talaria-shell/src/gui.rs:98-118`): `actions` accumulates inside
the closure; `tabs` is borrowed once at the top of `ctx.run` and explicitly dropped at
`crates/talaria-shell/src/gui.rs:310` before any central-panel work. Reading another `Shared` field
inside the closure is already done for sessions at `crates/talaria-shell/src/gui.rs:214`
(`let sessions = shared.sessions.borrow();`), so a shared borrow of the vault follows the same shape.
A mutable borrow of the vault inside the closure is the named anti-pattern — that is what the intents
are for.

The conditional-panel analog (`crates/talaria-shell/src/gui.rs:312-325`), the only non-strip surface
today, showing how a central panel replaces the page and how a button becomes an intent:

```rust
            if let Some(tab_id) = crashed_tab {
                // Crashed state replaces the page (same shape as "Aw, Snap").
                egui::CentralPanel::default().show(ctx, |ui| {
                    ui.vertical_centered(|ui| {
                        ui.add_space(ui.available_height() * 0.35);
                        ui.heading("💥 This tab crashed");
                        ui.label("The page's rendering process went away.");
                        ui.add_space(8.0);
                        if ui.button("Reload").clicked() {

```

Replacing the page this way also avoids the framebuffer blit at
`crates/talaria-shell/src/gui.rs:327-349` entirely, since the blit is inside an `if let Some(..)` on

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page script -> chrome | A hostile page must not be able to read or influence anything the credentials surface holds |
| agent (MCP) -> chrome | An agent must not be able to open the panel, trigger the suggestion, or observe either |
| chrome -> vault | The only write path into the encrypted credential store |
| chrome -> clipboard | Copying a password puts it somewhere other applications can read |
