them. This plan lands everything else, so 04-03's manifest touch is two lines rather than a
dependency plan of its own.

**Cargo feature unification, stated so it is not a surprise:** once 04-03 adds the edge,
`talaria-mcp` asks for `stdio` and `talaria-shell` asks for `streamable-http` and `auth`; Cargo
unifies them, so the `talaria-mcp` binary is built against an SDK with all five features enabled. That changes nothing about its
behaviour — it never constructs an HTTP transport — but it does mean the stdio binary grows. Say so
in the SUMMARY.
